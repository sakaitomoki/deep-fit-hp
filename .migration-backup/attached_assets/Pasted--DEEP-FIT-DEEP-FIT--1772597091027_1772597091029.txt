# DEEP.FIT サーキット×キックボクシングジム ウェブサイト構築プロンプト

## プロジェクト概要

兵庫県尼崎市にあるサーキットトレーニング×キックボクシングジム「DEEP.FIT」のプロフェッショナルな日本語マルチページウェブサイトを構築してください。

### ジムのコンセプト
- ブランド名: DEEP.FIT（ディープフィット）
- タグライン: 「動いて、整えて、気づけば続く。」
- 英語サブタイトル: CIRCUIT × KICKBOXING GYM
- ターゲット層: 20代〜70代（初心者・女性も多く在籍）
- コンセプト: 「運動は初めてで不安」「ジムに入っても続かなかった」そんな方こそ、安心して始められる環境づくりを大切にしている

---

## 技術スタック

- **フロントエンド**: React + Vite + TailwindCSS + Framer Motion
- **バックエンド**: Express.js
- **データベース**: PostgreSQL（Drizzle ORM）
- **ルーティング**: wouter
- **データフェッチ**: TanStack React Query v5
- **フォーム**: react-hook-form + zodResolver
- **SEO**: react-helmet-async
- **アイコン**: lucide-react（UIアイコン）、react-icons/si（SNSロゴ）
- **UIコンポーネント**: shadcn/ui（Button, Badge, Input, Textarea, Select, Form, Toaster, Tooltip）

---

## デザインシステム

### カラースキーム
- プライマリグレー: `#4D5058`（ナビ背景、見出し、ダークセクション背景）
- セカンダリグレー: `#53565E`（グラデーション副色、サブテキスト）
- アクセントオレンジ: `#F2AC55`（CTA、ハイライト、アクティブ状態、星評価）
- オレンジホバー: `#D99A40`（ボタンホバー時）
- 背景グレー: `#F2F3F5`（セクション交互背景）
- テキスト不透明度: `text-[#4D5058]/70`（本文）、`text-[#4D5058]/60`（補足）、`text-[#4D5058]/50`（薄めの補足）

### フォント
- 日本語本文: Noto Sans JP
- 英語見出し・ロゴ: Oswald（`font-heading`としてTailwindに設定）

### デザインパターン
- セクション見出し: 英語ラベル（小文字tracking-[0.3em]オレンジ）+ 日本語大見出し（グレー太字）の2段構成
- カード: `rounded-2xl`（ホーム）/ `rounded-md`（その他ページ）
- ボタン: `rounded-full`（CTA系）/ `rounded-md`（通常）
- グラデーションオーバーレイ: 画像の上に `bg-gradient-to-b from-[#4D5058]/80 via-[#4D5058]/70 to-[#4D5058]/90`

## 共通コンポーネント

### Navigation（固定ヘッダー）
- スクロール20px以上で背景が `bg-[#4D5058]/95 backdrop-blur-md` に変化（それ以前は透明）

- 4カラムグリッド: ロゴ+説明+SNSアイコン / ページリンク / お問い合わせ情報 / 営業時間

### GymLogo コンポーネント
- ロゴ画像を表示、sm/md/lgのサイズバリエーション

### ScrollToTop
- ページ遷移時に自動でトップにスクロール

## ページ構成

### 1. ホーム（/）— 最もリッチなアニメーション

#### ヒーローセクション（全画面高さ）
- **Ken Burns効果**: 背景画像が`scale: 1.2 → 1`に8秒かけてズームアウト
- **パララックス**: スクロールに応じて背景がY方向に移動（0→200px）、コンテンツは透明度が1→0にフェード
- **テキストアニメーション**:
  - 英語ラベル「CIRCUIT × KICKBOXING GYM」がフェードイン（ボーダー付きピル型）
  - 「DEEP.FIT」が大文字で表示（text-5xl〜8xl、Oswald）
  - 「サーキットトレーニング×キックボクシング」がフェードイン
  - タグライン「動いて、整えて、気づけば続く。」が**1文字ずつ**アニメーション表示（delay: 1.2秒開始、各文字0.06秒間隔）
- **CTAボタン**: 「体験レッスンを予約」（GlowButton・オレンジ）、「クラス・料金を見る」（アウトライン白）
- **スクロールインジケーター**: 下部にバウンスアニメーション（丸い枠+オレンジの点が上下に動く）

#### GlowButton コンポーネント
- ホバー時に背後にオレンジのぼかしグロー効果が表示される（`bg-[#F2AC55]/30 blur-md`）

#### ScrollProgress コンポーネント
- ページ上部に固定されたオレンジのプログレスバー（z-[60]）
- useScrollとuseSpringで滑らかに動く

#### 「選ばれる理由」セクション（白背景 + グリッド背景パターン）
- 4カラムグリッド: 初心者歓迎（Users）、幅広い年齢層（Trophy）、充実の設備（Dumbbell）、続けられる仕組み（Clock）
- カードは`scaleIn`アニメーション + ホバーで`y: -8`上昇
- アイコンはホバー時にオレンジ背景+白アイコンに変化
- カード全体にグラデーションオーバーレイがホバーで出現

#### 「ジムについて」セクション（背景画像+ダークオーバーレイ）
- 左: テキスト（タグライン、説明文、「ジムについて詳しく」GlowButton）
- 右: 4つの数字統計カード（グラスモーフィズム: `bg-white/5 backdrop-blur-md border-white/10`）
  - 会員数 500+、運営実績 8年+、クラス/週 15+、プロ在籍 5名
  - **CountUpコンポーネント**: useInViewで画面内に入ったら0から目標値まで2秒間でカウントアップ（requestAnimationFrameベース60fps）
  - ホバーで`scale: 1.05`

#### 「クラス紹介」セクション（#F2F3F5背景）
- 3カラムグリッド: フィットネス、パーソナルトレーニング、キッズクラス
- カードに画像（ホバーで`scale: 1.1`ズーム）+ グラデーションオーバーレイ + レベルバッジ
- 左カードは`fadeInLeft`、中央は`fadeInUp`、右は`fadeInRight`
- 「全てのクラスを見る」ボタン（グレー背景・丸型）

#### 「お客様の声」セクション（背景画像+ダークオーバーレイ）
- **TestimonialCarousel**: AnimatePresenceで左右スライド切替
  - 3件の口コミを自動ローテーション（5秒間隔）
  - 手動で前後ボタン＋ドットナビゲーションで切替可能
  - グラスモーフィズムカード（`bg-white/5 backdrop-blur-sm border-white/10 rounded-2xl`）
  - 5つ星評価（fill-[#F2AC55]）、引用テキスト、名前と肩書き
- 口コミデータ:
  - 田中 美咲（会員歴2年・30代女性）
  - 山本 健太（会員歴3年・40代男性）
  - 佐藤 由美（会員歴1年・60代女性）

#### 「体験レッスン受付中」CTAセクション
- 全面オレンジグラデーション背景（`from-[#F2AC55] via-[#F2AC55] to-[#D99A40]`）
- 動くドットパターン背景（radial-gradient、20秒で往復アニメーション）
- 体験価格表示、「体験レッスンを申し込む」（白ボタン+グロー）、「電話で予約」（アウトラインボタン）

#### Framer Motionアニメーション定義
```
fadeInUp: opacity 0→1, y 40→0, duration 0.7, ease [0.25, 0.46, 0.45, 0.94]
fadeInLeft: opacity 0→1, x -60→0, 同上
fadeInRight: opacity 0→1, x 60→0, 同上
staggerContainer: staggerChildren 0.15
scaleIn: opacity 0→1, scale 0.8→1, duration 0.6
```

## レスポンシブ対応

- **ナビゲーション**: lg以上でフルメニュー、lg未満でハンバーガー
- **グリッド**: 1カラム（モバイル） → 2カラム（sm/md） → 4カラム（lg）
- **テキストサイズ**: モバイルは小さめ、sm/md/lgで段階的に拡大
- **ヒーローテキスト**: text-5xl → sm:6xl → md:7xl → lg:8xl
- **カルーセル最小高さ**: min-h-[200px] sm:min-h-[180px]
- **About「2015設立」バッジ**: md以上のみ表示

---

## アクセシビリティ・テスト対応

- 全インタラクティブ要素に `data-testid` を付与
  - パターン: `button-{action}`, `input-{field}`, `link-{target}`, `select-{name}`
  - 動的要素: `button-testimonial-dot-${index}`, `img-instructor-${index}`
- カルーセルのボタンに `aria-label`（「前へ」「次へ」「スライド N」）
- モバイルメニューボタンに `aria-label="メニュー"`

## App.tsx の構成

App.tsxは以下のプロバイダーとグローバルコンポーネントで構成:

```
HelmetProvider
  └ QueryClientProvider (TanStack React Query)
    └ TooltipProvider
      ├ ScrollToTop（useLocationでページ遷移を検知し、window.scrollTo(0,0)を実行）
      ├ Navigation（全ページ共通・固定ヘッダー）
      ├ <main>
      │   └ Router（Switch + Route: /, /about, /schedule, /instructors, /contact, 404）
      ├ Footer（全ページ共通）
      └ Toaster（トースト通知）
```

## 注意事項

1. ホームページは特にアニメーションが豊富で印象的なものにすること（Ken Burns、パララックス、文字送り、カウントアップ、カルーセル、グロー効果、スクロールプログレスバー）
2. 他のページ（About, Schedule, Instructors, Contact）もFramer Motionの`fadeInUp`と`staggerContainer`で統一的なアニメーションを適用
3. カラーはTailwindのプリセットカラー（orange-500等）を使わず、すべてHEX値を直接指定（`text-[#F2AC55]`形式）
4. 全ページで`whileInView`と`viewport={{ once: true }}`を使用し、スクロールで初回のみアニメーション
5. フォームの電話番号フィールドはnullable。`value={field.value ?? ""}` でnull時のエラーを防止
6. ナビゲーションのスクロール検知は20pxを閾値とする
7. GlowButton、ScrollProgress、TestimonialCarousel、CountUpの4コンポーネントはHome.tsx内に直接定義する（別ファイル不要）
8. DBスキーマのinquiry_typeカラムはDrizzle側でcamelCase `inquiryType` としてマッピングされる
9. Storage層はIStorageインターフェースを定義し、createContactInquiry / getContactInquiries メソッドを持つ
