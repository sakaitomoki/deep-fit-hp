DEEP.FIT の公式サイトに SEO 実装を行ってください。
目的は「JR尼崎 / 尼崎 / キックボクシング / 初心者 / 女性 / 無料体験」系の検索意図に対して、検索エンジンがページ内容を理解しやすくし、ローカル集客を強化することです。

【前提方針】
- ただのSEOタグ追加ではなく、ページ単位で検索意図に合わせて実装すること
- キーワード詰め込みは禁止
- すべて自然な日本語にすること
- 検索エンジン向けとユーザー向けの両方で意味が通るようにすること
- React / Next / Vite など現行構成に合わせて実装すること
- 既存のデザインやUIは崩さずに対応すること

====================
1. 各ページの title / meta description / canonical を実装
====================

以下を最低限ページごとに設定すること。
- title
- meta description
- canonical
- og:title
- og:description
- og:image
- og:type
- twitter:card
- twitter:title
- twitter:description
- twitter:image

ページ別のたたき台は以下。

■ トップページ
title:
JR尼崎のキックボクシングジムならDEEP.FIT｜初心者・女性歓迎・無料体験受付中

meta description:
DEEP.FITはJR尼崎駅徒歩10分のサーキット×キックボクシングジムです。初心者・女性・一人参加でも通いやすく、綺麗で広い空間と個室スミスマシンも完備。無料体験受付中。

■ ジム紹介ページがある場合
title:
DEEP.FITってどんなジム？｜綺麗で広い空間・女性も通いやすい尼崎のキックボクシングジム

meta description:
綺麗で広い空間、和気藹々とした雰囲気、個室スミスマシン完備。DEEP.FITは初心者や女性でも通いやすく、一人で集中したい日も楽しく動きたい日も選べるジムです。

■ クラス紹介ページがある場合
title:
クラス紹介｜初心者向けフィットネス・パーソナル・キッズクラス｜DEEP.FIT 尼崎

meta description:
DEEP.FITのクラス紹介ページです。初心者向けフィットネス、パーソナルトレーニング、キッズクラスなど、目的に合わせて選べるクラスをご案内します。

■ インストラクターページがある場合
title:
インストラクター紹介｜DEEP.FIT 尼崎

meta description:
DEEP.FITのインストラクター紹介です。初心者や女性でも安心して通えるよう、丁寧なサポートを大切にしています。

■ お問い合わせ / 体験予約ページがある場合
title:
無料体験・お問い合わせ｜DEEP.FIT 尼崎

meta description:
DEEP.FITの無料体験予約・お問い合わせページです。見学だけでもOK。運動が久しぶりの方や初心者の方もお気軽にご相談ください。

canonical は各ページの正式URLを入れること。
URLの重複があれば canonical で正規化すること。

====================
2. 見出し構造をSEO・可読性の両面で整理
====================

- 各ページに H1 は 1つだけ
- H2 / H3 の階層を整理
- 見出しは検索意図と自然な日本語の両立を優先
- デザイン都合で div を見出しにしている箇所があれば、適切な hタグへ修正

トップページの推奨H1:
JR尼崎で初心者・女性も通いやすいキックボクシングジム

ただし、デザイン上メインコピー「楽しいから続く。続くから変わる。」を見せたい場合は、
視覚表現は維持しつつ、HTML上は SEO向けの H1 を別に適切配置してよい。

====================
3. LocalBusiness / SportsActivityLocation の構造化データを実装
====================

JSON-LD で以下を実装すること。
候補:
- LocalBusiness
- SportsActivityLocation
- HealthClub
- Gym

最も適切な schema.org タイプを選ぶこと。
最低限含める項目:
- @context
- @type
- name: DEEP.FIT
- url
- logo
- image
- telephone
- address
- geo（可能なら）
- openingHoursSpecification
- sameAs（Instagram 等）
- areaServed
- description

体験予約ページやFAQページが独立している場合は、必要に応じて
- FAQPage
も追加すること。

FAQPage を使う場合は、実際にページ上に見えているQ&Aだけをマークアップすること。

====================
4. 画像SEOを実装
====================

- すべての主要画像に適切な alt を設定
- alt はキーワード詰め込み禁止
- 内容を自然に説明すること
- 画像ファイル名も可能なら意味のある英数字に変更
  例:
  deepfit-amagasaki-gym-interior.jpg
  deepfit-smith-machine-private-room.jpg
  deepfit-kickboxing-class-beginners.jpg

例 alt:
- DEEP.FITの広く清潔感のあるジム内観
- DEEP.FITの個室スミスマシン設備
- 初心者向けキックボクシングレッスンの様子
- 女性会員がトレーニングしているDEEP.FITの雰囲気

OG 画像も専用画像を設定すること。
ロゴ単体ではなく、ジムの雰囲気が伝わる代表画像を優先。

====================
5. sitemap.xml と robots.txt を整備
====================

- sitemap.xml を自動生成または静的生成
- すべての公開ページURLを含める
- robots.txt を作成
- robots.txt に sitemap のURLを記載
- noindex にすべきページがあれば個別に設定
  例:
  完全なサンクスページ
  テストページ
  下書きページ

====================
6. 内部リンクをSEO向けに改善
====================

- ナビゲーションやボタンは、可能な限り <a href> ベースでクロール可能にする
- JS onclick だけで遷移している箇所があれば修正
- アンカーテキストは意味のある文言にする
- 「詳しくはこちら」だけではなく、内容が分かる文言を使う

例:
- クラス紹介を見る
- 無料体験を予約する
- ジムの雰囲気を見る
- よくある質問を見る

====================
7. Core Web Vitals / 表示速度対策
====================

以下を実装または確認すること。
- ヒーロー動画や大きい画像の読み込み最適化
- 画像の lazy loading
- 画像サイズ最適化（WebP / AVIF 対応可能なら対応）
- CLS が出ないよう width / height を確保
- フォントの読み込み最適化
- 不要なJSや重いライブラリの削減
- INP に悪影響が出る重い初期処理を避ける
- LCP 対象のヒーロー要素は優先ロード

必要なら Lighthouse / PageSpeed Insights を前提に改善しやすい構成にすること。

====================
8. ローカルSEO向けの文言整理
====================

トップページ・主要セクション内に、過度でない範囲で以下の地域性を自然に入れること。
- JR尼崎
- 尼崎
- 徒歩10分
- 初心者
- 女性歓迎
- 無料体験
- キックボクシングジム
- サーキットトレーニング

ただし、不自然な詰め込みはしない。
見出し・本文・alt・title・meta description に分散して自然に反映すること。

====================
9. Google Business Profile / NAP整合
====================

サイト内の店舗情報を以下と整合させる前提で整理すること。
- 店名
- 住所
- 電話番号
- 営業時間

フッター、構造化データ、問い合わせ導線、予約導線で情報の不一致がないようにすること。
